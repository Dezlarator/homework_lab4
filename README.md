У босса 1000 единиц здоровья. С клавиатуры вводятся уровни силы трёх героев (целые числа). Если уровень силы каждого из трёх героев кратен 3, герои наносят тройной урон: здоровье босса уменьшается на сумму уровней силы, умноженную на 3, и выводится потерянное здоровье и текущее здоровье босса. В остальных случаях здоровье босса уменьшается на сумму уровней силы, и выводится текущее здоровье босса.

Алгоритм и блок-схема
Алгоритм решения
1. Начало
2. Присвоить здоровью босса значение: healboss = 1000.
3. Ввести уровни силы героев A, B и C.
4. Проверить условие: A mod 3 = 0 и B mod 3 = 0 и C mod 3 = 0.
5. Если условие выполняется: healboss = healboss − (A + B + C) · 3. Вывести потерянное здоровье (A + B + C) · 3 и текущее здоровье босса.
6. Если условие не выполняется: healboss = healboss − (A + B + C). Вывести текущее здоровье босса.
7. КОНЕЦ
